# Eingang

Hier landet Rohmaterial, das ein Agent verarbeiten soll: Meeting-Transkripte, Mails, Feedback, Mitschriften. Die Dateien bleiben lokal. Außer dieser Datei ist der Ordner von git ausgenommen, weil das Material Namen und Aussagen Dritter enthält.

Ablegen als `JJJJ-MM-TT_kurztitel.md` oder `.txt`. Danach dem Agent sagen: „Verarbeite den Eingang.“ Material, das ein Skript noch liest, etwa Übungsdaten, bleibt hier, bis die Arbeit damit abgeschlossen ist. Seine Herkunft steht im Protokoll. Was der Agent daraus macht, regelt [CLAUDE.md](../CLAUDE.md) unter „Processing the inbox“.
